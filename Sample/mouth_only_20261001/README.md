# 口の周囲透明化（2026-10-01）

この記録内のPSD・PNG・中間データ・作業スクリプトはローカル資料で、GitHubへの同期対象外。[資料の管理方針](../README.md)を参照。

ユーザーが眉の修正を成功と評価し、口にも周囲透明化を適用するよう指示。開いたままの文書（PID33060、修正前revision=4）からジョブを発行し、口だけをreplace_layerで置換した。文書の復帰・再読込は行っていない。

元画像の口輪郭を基に、唇の色と口内の明るい部分を保持し、周囲の肌を透明化。薄い口内画素が穴にならないよう、各行の口の輪郭内は元画素を保持した。この原画専用の輪郭・色指定であり、汎用的な自動分離ではない。生成・再描画・拡縮は行っていない。

画像は45×17、元キャンバス座標(495,215)～(540,232)を維持。残した105画素は原画RGBAと一致し、660画素は透明。アプリから再書出しした口画像とも全画素一致。目・眉・ベース・元画像のPNGハッシュ、全レイヤーの順序・名称・座標・表示・不透明度は変更前後で一致した。

取込completed、revision=5、modified=true、canUndo=trueを確認。既存PSD原本は変更せず、別名の確認用PSDを保存した。その後、ユーザーが口を含む最終結果を成功と確認し採用。GPT-6 Astra・推論「高」での成功として、ベースの消去・肌色補完、全パーツのサイズ・位置、範囲外の透明化をnote.mdへ記録した。mouth_only_review.psdを採用済みの完成確認データとする。[再利用ガイド](../../Codex再利用ガイド.md)から別ユーザー向け手順を参照できる。
