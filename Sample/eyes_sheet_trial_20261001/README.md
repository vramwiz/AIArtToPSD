# 両目6種類の横長シート生成・アプリ追加

この記録内のPSD・PNG・中間データ・作業スクリプトはローカル資料で、GitHubへの同期対象外。[資料の管理方針](../README.md)を参照。

2026-10-01。通常・閉じ・半開きを基本に、画角に収まる数の両目差分を生成するユーザー依頼。内蔵image_genで1536×1024、2列×3段の透明シートを1回生成し、6種類を開いている文書へ追加した。**ユーザーが「目も問題ない」と確認し、6種類を成功例として採用済み。** 会話の作業条件はユーザー指定のGPT-6 Astra・高。画像生成内部モデルは未特定。

![アプリが縮小した両目6種類の比較](face_comparison.png)

## 作成内容

| 順番 | 差分 | アプリ出力PNG | 主要可視範囲（alpha>16） |
| --- | --- | --- | --- |
| 01 | 通常 | 128×44 | 122×34 |
| 02 | 閉じ | 121×43 | 120×18 |
| 03 | 半開き | 125×37 | 122×26 |
| 04 | 笑顔閉じ | 119×29 | 118×22 |
| 05 | ほぼ閉じ | 121×30 | 120×22 |
| 06 | 見開き | 125×42 | 124×37 |

左右の目を別々に生成・拡縮せず、全差分を両目一組として扱った。基本3種に加え、上向きの弧で閉じる笑顔、細い開口のほぼ閉じ、通常より縦に開く見開きを配置。全体の可視範囲の高さには左右の目の高低差・まつ毛・まぶた線が含まれるため、開口率そのものではない。

生成では髪・眉・周囲の肌・背景光を禁止し、眼球内部の白目やハイライトを保持するよう指定。チェッカーと顔への実合成では髪や大きな肌パッチの混入、広い光の重なりは見られなかった。まぶたに沿う薄い線は目の一部として保持した。生成画像単独の表示では背景光のようなRGBが見えるが、通常のアルファ合成で判断した。微小な半透明画素は残り、alpha=0だけを詰めるtrimTransparentの外枠は主要可視範囲より大きい。

「通常」もAIが描いた差分で、元画素の目と同一ではない。絵柄・開き方・目の間隔の細かな違いも含め、今回の結果はユーザー確認済み。元の両目PNGは無変更で保持する。連続アニメーション・音声連動は未検証。

## 配置と確認

各セルから640×220を切り出し、アプリのsourceBounds・resampleで128×44（共通倍率20%）へ縮小。全差分の横方向の主要可視範囲中心をx=507へ合わせ、目尻の位置を目視して選んだ各ペアの基準高さをy=174へ置いた。縮小前の配置は[measurements.json](measurements.json)、処理は[prepare_layout.ps1](prepare_layout.ps1)を参照。

閉じ目を開いた目と同じ高さまで拡大せず、曲線やまぶたの移動を保つ。位置の補正は両目一組に対する平行移動だけ。左右別々の座標補正・回転・形状変形は行っていない。笑顔閉じの可視範囲中心が他より3px高いのは上向きの弧を保つためで、可視範囲中心を機械的に同一yへ揃えていない。これらの手動基準と座標は今回の絵専用で、汎用的な自動ランドマーク検出ではない。

アプリ取込前に[draft_comparison.png](draft_comparison.png)で形と配置を確認し、取込後はアプリ出力の個別PNGで[face_comparison.png](face_comparison.png)を作成して再確認した。下書きだけGDI+補間、納品画像はアプリのアルファを考慮した縮小結果。

## 開いているアプリ

「目差分6種（両目・確認用）」を既存顔グループへ追加。「02 閉じ」だけを表示し、「目（両目・元画素）」は非表示で保持。各差分を見る際は現在の目を非表示にして別の目を一つ表示する。自動排他切替の設定はしていない。

取込時点の口は「05 い」が表示されており、その状態と口9種類を保持した。既存画像15枚のSHA-256、座標、階層、相対順序、不透明度等が不変であることを確認。既存の変更は原画の目の表示状態だけ。importはcompleted、revision 25→26、Undo可能。確認用exportは保存後cancelしたため、画面の最新ジョブが中止でも取込成功は取り消されていない。

コード変更なし。現在の文書は未保存扱いのまま、以下のPSDを別ファイルへ保存。既存PSD原本を上書きしていない。
