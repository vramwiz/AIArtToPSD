# 顔の正方形作業領域とアプリ側サイズ補正（2026-10-01）

この記録内のPSD・PNG・中間データ・作業スクリプトはローカル資料で、GitHubへの同期対象外。[資料の管理方針](../README.md)を参照。

会話の作業条件は **GPT-6 Astra・推論「高」**（ユーザー確認済み）。生成は内蔵image_genを使用し、内部の画像生成モデルは未特定。ユーザーは縮小等の機能をアプリ側に持たせて続行することを承認し、顔全体を共通の正方形で扱う方式を提案した。

## 実装と正方形方式の結果

アプリへ拡縮・配置・完全透明な外側余白の除去、正方形作業画像の書出し、共通座標から元キャンバスへの復元を追加。生成や意味的なパーツ分離はAIが担当し、プログラムによる輪郭マスク・肌補完は行っていない。既存パイプとresult.jsonの任意項目を使用し、手動編集UIは追加していない。詳細は[交換仕様](../../アプリ実装_AI画像指示交換.md)。

元絵1024×1536内の (384,64)～(640,320)、辺長256を作業画像1024×1024としてアプリから書き出した。元絵への変換は `x=384+u/4、y=64+v/4`。元画像レイヤーを指定し、補正済みの合成を入力にしない。

- 入力：[face_square_source.png](face_square_source.png)、1024×1024。
- 肌補完ベース：[base_square.png](base_square.png)、実出力1254×1254。
- 両目一組：[eyes_square_rejected.png](eyes_square_rejected.png)、実出力1254×1254。正方形内部の相対サイズ・位置が大きく変化し、不採用。
- 指示全文：[prompts.json](prompts.json)。ベース・両目を各1回で終了し、眉・口の追加生成には進まなかった。

実寸1254を共通枠256へ戻す倍率は256/1254。アプリはこの解像度差を扱えるが、画像内部でAIが行った拡大・移動は共通の倍率では直らない。正方形を使う構想は座標管理として実装できた一方、今回のAIによる位置維持は不成功。正方形の生成物はアプリの確認文書へ取り込んでいない。

## アプリで確認できるサイズ補正

ユーザー保存済み `PSD/立ち絵_gpt6Astra高.psd` を `review_start.psd` へコピーして開き、既存の両目・両眉・口・肌補完ベースを利用した。PSD原本・元PNGは変更していない。

アプリの新しい「サイズ補正（眉・口65％）」グループを表示。元グループと元画像は非表示で残し、Undo可能な一括取込として適用した。比較時は新旧グループを片方ずつ表示する。旧グループの口はユーザー保存時の非表示を保持しているため、旧口も見る場合はその目アイコンをオンにする。

| パーツ | 入力からの処理 | 取込後の実レイヤー矩形（元キャンバス） |
| --- | --- | --- |
| 両眉一組 | 全体を1024×1536→666×998（約65％）、配置補正、透明余白除去 | (458,136)～(560,169)、102×33 |
| 両目一組 | ユーザーが許容した生成物を維持 | (0,0)～(1024,1536) |
| 口 | 全体を1024×1536→666×998（約65％）、配置補正、透明余白除去 | (228,213)～(539,1004)、311×791 |
| ベース | 既存の肌補完・光除去結果を維持 | (0,0)～(1024,1536) |

縮小前の口はalpha>128の基準で60×23、原画の参考領域39×12に対し幅約1.54倍・高さ約1.92倍。幅を基準に65％を採用した。したがって高さや形が完全に原画へ戻る補正ではない。眉も既に左右一組で生成したもので、片眉を生成し直した結果ではない。

口レイヤーの広い実矩形は離れた微かなalpha>0の画素によるもの。今回の透明余白除去はalpha=0のみを除去し、薄い画素を閾値で捨てない。光・透明度の共通問題として残す。拡縮時はアルファ乗算済みの色で計算し、alpha=0の隠れた色が縁へ混入することを防いだ。

![左：元絵、中央：縮小前、右：アプリで眉・口を約65％に補正](resized_face_comparison.png)

眉・口の大きさは改善するが、眉の形・髪への重なり、口の開き方には差が残る。画像分離全体の完成とは認定しない。

- [size_adjusted_review.psd](size_adjusted_review.psd)：アプリのPSD書出しによる補正後の確認用文書。現在のアプリが閉じてもこれを開ける。
- [native_resized_preview.png](native_resized_preview.png)：実際のアプリ合成。
- [native_resized_layers.json](native_resized_layers.json)：実際のレイヤー座標・寸法。
- [resize-result.json](resize-result.json)：縮小前の元assetと配置指定。画素変換はアプリ内で行った。
- [prepare_resize_result.ps1](prepare_resize_result.ps1)：交換JSONの作成のみ。[compare_resized.ps1](compare_resized.ps1)：確認画像の描画のみ。
