# 目レイヤーの髪除去（2026-10-01）

この記録内のPSD・PNG・中間データ・作業スクリプトはローカル資料で、GitHubへの同期対象外。[資料の管理方針](../README.md)を参照。

ユーザー指示：「目に髪が入っているため目の変化で髪が変化する。髪部分は目のレイヤーには入れない追加ルール。他は問題ないので目だけをやり直す」。note.mdへ追加し、元画素の両目レイヤーだけを修正した。

アプリは文書未読込だったため、直前の矩形分離文書のスナップショットを復帰して作業。新しいジョブのreplace_layer一件で目を置換し、取込completed、revision=2、canUndo=trueを確認した。眉・口・ベース・元画像のPNGハッシュ、全レイヤーの名前・順序・座標・表示・不透明度を変更前後で照合し、一致を確認。

目の外形は先行の元画素試験で使用した左右の輪郭マスクを利用し、目尻などの髪接触領域の青灰色画素も透明化した。この絵専用の指定であり、自動的な汎用髪判定ではない。青い虹彩を削除しないよう全体への色抜きは行っていない。両目は一枚で、サイズ133×46、元キャンバス座標(439,153)～(572,199)を維持。残した2,341画素は原画RGBAと一致、3,777画素を透明にした。再生成・再描画・拡縮は行っていない。必要な周辺肌は残る。

- eyes_no_hair.png：修正した両目一組のPNG。
- eyes_review.png：上が旧矩形、下が髪除去後の8倍表示。チェッカーは確認画像だけに描画。
- face_review.png／native_preview.png：アプリの合成確認。
- eyes_no_hair_review.psd：アプリが書き出した別名の確認用PSD。既存PSD原本は変更なし。
- result.json：目だけの置換操作。
- prepare_eyes.ps1／prepare_result.ps1／verify.ps1：再現用処理・取込指示・検証。
- verification.json：他レイヤーとメタデータの不変、元画素一致の検証結果。実アプリ書出しの目PNGとも全画素一致を確認。

アプリコード修正は不要。今回の処理にimage_genは使っていない。確認用書出しジョブはスナップショット取得後に中止したため、状態欄の中止表示は目レイヤーの取込失敗ではない。ユーザーは編集画面で確認でき、目の置換をUndoできる。
