## 出力と確認結果

### base_generated.png

目・眉・口を消して肌を補完したベース候補。目視では肌がつながり、旧試験の透明な穴はない。旧左目中心付近 (470,180) は RGBA=(253,221,201,251)、右目付近 (540,170) は (253,222,201,250)。

ただし、元画像の alpha>0 は393,845画素なのに対し、生成ベースは1,572,864画素（全画素）で alpha>0。元画像にあった完全透明領域が失われた。alpha>128 の範囲も画面端へ広がっている。顔だけの局所編集として元の透明度を保持する条件に不合格。髪・衣服等の画素完全保持も認定していない。

### eye_left_rejected.png

画面左の目だけを元のキャンバス位置で透明レイヤーにする試験。キャンバス寸法は維持されたが、目視で目の形状・傾きが変化。過去の元画素切り抜きの範囲は x=442..497, y=163..194、生成された alpha>240 の範囲は x=441..490, y=167..204。過去の切り抜きは周辺肌を含む近似であり、この範囲比較だけを厳密な位置誤差測定とは扱わないが、無調整で同じ目を戻す品質を確認できていない。

alpha>0 は2,675画素、alpha>128 は1,577画素。生成プレビューの目の周囲には広い光が見えたが、検査した周辺点のalphaは0で、透明RGB情報が表示されていたと考えられる。広い背景光の見た目だけを不合格理由にはしない。離れた低alpha画素もあり、alpha>0の範囲は x=429..865, y=159..1127。

## ユーザー指示による光除去の再試験

初回指示に `background glow` を維持する指定が入っていた。透明画素のRGBにも光が含まれるため、生成側がこれを背景として描き直した可能性がある。因果関係の確定ではないが、光・霞・影の除去と完全透明化を明示して再試験した。

- `base_no_glow_v2.png`：初回ベースを内蔵image_genで修正。チェッカー背景へ通常のアルファ合成で描画すると、初回の広い汚れは消えた。alpha>0は全1,572,864画素から389,361画素へ減少（元画像393,845画素）。周辺の確認点 (0,0)、(250,700)、(350,1100)、(750,750)、(512,1520) はすべてalpha=0。目の跡は肌で埋まっている。低alpha画素は人物外にも残り、元画像との画素完全一致や透明度完全一致は認定しない。人物細部の描き直しもある。
- `eye_left_v2_rejected.png`：元画像から片目を再分離。alpha>128範囲は x=406..455, y=167..205。元画素の旧切り抜き範囲 x=442..497, y=163..194 と比べて明確に左へ移動。補正せずベースに重ねると髪にかかり、目の形も変わっているため不採用。光除去だけで分離全体が成立するわけではなかった。
- `retry_alpha_review.png`：元画像／初回ベース／再試験ベースを同じチェッカー背景に通常合成した比較。ツールの生成プレビューで見える透明RGBの光と、実際に合成される半透明汚れを区別する。
- `retry_face_review.png`：元画像／修正ベース／修正ベース＋再試験片目の顔拡大。片目はキャンバス原点(0,0)へ無調整で合成。

指示全文は `retry_prompts.json` と `retry_eye_prompt.json`、数値は `verification_retry.json`。生成PNGは無加工コピー。PowerShellは検査と比較用の通常描画だけで、分離・肌補完・アルファ修正・位置合わせは行っていない。

再検査：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File Sample/ai_separation_check_20261001/inspect.ps1 -IncludeRetry -ReportName verification_retry.json`。比較描画：同フォルダーの `render_retry_review.ps1` をWindows PowerShell 5.1で実行。

この再試験時点では、肌補完ベースの光除去が改善し、元の形・位置でのAIパーツ分離は未達。PSD作成・アプリ取込へは進めず停止した。その後の両目一組の限定試験は以下に記録する。

光・透明度の問題はこのベースだけの個別課題ではなく、分離・補完・差分生成・再合成に共通する問題として、[note.mdの共通問題点](../../note.md#共通の問題点光透明度の扱い)へ記録した。今回の光除去による改善と、別に残る形状・位置の問題を区別して引き継ぐ。
