ユーザー指示で髪の分離を断念し、Sample/character_neutral.pngの左右の目・左右の眉の可視部分・口を、元の座標とRGBA画素を使って分離した。画像生成は使っていない。ユーザー承認済みのPython切り抜きと、アプリのAI交換・パイプ機能を使用した。

起動中のAIArtToPSD（PID 7572）は文書未読込だったため、アプリの実装で元画像の復帰ジョブを作成し、recover → progress → importの順で送信した。取込応答はcompleted、版1、canUndo=true、modified=true、canEdit=true。アプリに次の内容が入っている。

- 顔パーツ（分離試験）グループ：目（画面左）、目（画面右）、眉（画面左・可視部のみ）、眉（画面右・可視部のみ）、口。
- 残り（顔パーツ以外・補完なし）：通常表示。
- 元画像（比較用）：非表示。

元画像・既存PSD原本を変更せず、未保存の試験文書として取り込んだ。交換結果はこのフォルダーのexchange配下に保存してあり、job-directory.txtがジョブ位置を示す。アプリではレイヤーの表示を切り替えて確認し、必要ならPSDとして保存する。

## 結果と制約

comparison.pngの上段は元画像・左右の目・左眉、下段は右眉・口・残り・再合成。元画像の可視RGBAと透明度は、Pythonでの再合成と完全一致（変更画素0）。verification.jsonに各パーツの手動指定輪郭と画素数を記録した。

この画像の専用マスクであり、自動的な顔検出・汎用分離ではない。目は白目・虹彩・まつ毛をまとめた1枚で、周辺の肌色を少量含む。口にも元画像の唇・周辺の肌色が含まれる。境界は元画像を見て調整した近似。左眉は前髪に隠れており、見えている部分だけなので途切れる。隠れた眉や肌の生成、白目と虹彩の分離、閉じ目や口の表情差分は未実施。パーツを消すと透明な穴が開く。

## 表示切替不具合の修正と保存PSDの確認

ユーザーから表示・非表示が切り替わらないと報告された。原因は、閲覧専用化でRebuildTreeがEditEnabledをfalseにする一方、目アイコンの処理も同じフラグに依存していたこと。ArtLayerListへVisibilityEnabledを分離し、MainFormから編集対応文書・処理中でない場合に有効にした。名前変更と不透明度スライダーは閲覧モードのまま。

ユーザー保存の `PSD/立ち絵.psd` を読み取り、アプリの実装で顔パーツのみ・左目のみを描画した。顔パーツの可視画素は2,782、左目だけでは1,278。身体や元画像の重複は描画されず、元画像レイヤーは非表示。原本PSDは上書きしていない。ネイティブ描画から作った比較画像はnative_isolation_comparison.png。

アプリとVisibilitySmoke・ExchangeUiSmokeのWin64 Debug／Release Rebuildは警告0・エラー0（VisibilitySmokeの未使用変数ヒントも除去済み）。VisibilitySmokeは両構成48項目合格：PNG、AI取込後、保存PSD、画像・グループ・スクロール後の目アイコン、Undo／Redo、名前編集・不透明度の閲覧モード維持、元画像との合成一致、顔のみ・左目のみの描画、別名保存後の切替。ExchangeUiSmokeは両構成23項目合格。git diff --checkも確認済み。既存UiSmokeは過去の手動編集UIを前提にするため、この修正では全実行していない。

修正版実行ファイルはプロジェクト直下のAIArtToPSD.exe。アプリを起動し直して保存済みPSDを開くと、目のアイコンで確認できる。「残り」を非表示にすると顔パーツのみ、他の顔パーツも非表示にすると対象1パーツのみを確認できる。今回の成果は周辺の肌を含む切り抜きであり、肌を復元した表情切替用パーツの完成ではない。
