# 最初の表情差分：少し開いた口（2026-10-01）

ユーザーが「まずはどこか1部位でもよい」と表情差分の検証を指示。口だけを選び、採用済みの顔・口を参照して内蔵image_genで「少し開いた口」を1回生成した。入力画像・指示全文は[prompt.json](prompt.json)。会話の作業条件はこれまでのGPT-6 Astra・推論「高」の記録を継続し、画像生成内部モデルは未特定。

## 結果

口単独の新規差分をアプリへ追加し、口だけで表情が変わることを実合成で確認した。**その後、ユーザーが「差分も問題ない」と確認し、採用済みの成功例として記録した。** 元の顔パーツ分離に加え、1部位の表情差分も成立した。再利用手順は[PSD立ち絵生成ルール](../../PSD立ち絵生成ルール.md#表情差分の再利用手順)を参照。

![左：元の口、右：少し開いた口](face_comparison.png)

アプリが終了していたため、採用済みmouth_only_review.psdをreview_start.psdへコピーし、そのコピーを新しく起動したアプリで開いた。元の採用済みPSDは変更していない。

「口差分（少し開く・試験）」を元の口の直上に追加して表示し、「口（元画素）」は非表示にした。目アイコンで差分をオフ、元の口をオンにすると比較できる。両方同時には表示しない。この試験では手動の表示切替を使い、排他的な表情グループ化は行っていない。

## 解像度・透明度と配置

生成器の出力は1774×887。alpha>16の口本体は(676,380)～(1098,521)。alpha>0の微細な残りは(434,157)～(1544,831)まで広がっていたため、口本体の周囲に8ピクセルの余裕を持たせた(668,372)～(1106,529)をアプリのsourceBoundsで切り出した。口の半透明輪郭は範囲内で保持し、範囲外の不要画素を除いた。数値は[alpha.json](alpha.json)。

アプリのresampleで438×157から33×12へ縮小し、元キャンバスの(496,218)～(529,230)へ配置。元の口の可視部分は(498,220)～(527,227)、29×7で、水平中心512.5を共通にした。開口の差分なので高さを元の閉じ気味の口と同一にはせず、少し下まで開く表現とした。生成画像が原寸や元位置を自動維持できたという検証ではない。

残りの処理はアプリ側の矩形切り出し・縮小・透明余白除去・配置のみ。新しい口の形をプログラムで描画したり、顔全体を再生成したりしていない。

## 検証・保存

取込completed、revision=1、modified=true、canUndo=trueを確認。既存の目・眉・元の口・ベース・比較元画像はすべてPNGハッシュ一致。既存レイヤーの名前・配置・不透明度等も保持し、元の口のvisibleだけをfalseにした。新規レイヤーは一枚のみ。アプリコード変更は不要だった。
