# Sample画像のレイヤー分解試験

入力: ../character_neutral.png（1024×1536）。
画像生成スキルの組み込みimage_genを使用。元画像は変更していない。

結果:
- 背景、頭部（髪・顔）、体と服の3画像を生成し、アプリのAI交換APIを通して取り込み、PSD保存に成功。
- PSDには比較用の原画像1レイヤーと、試作3レイヤーを含む非表示グループを保持。
- 独立したpsd-tools/Pillow照合で、3パーツと原画像のRGBA画素がPSD保存後も完全一致することを確認。
- 透過部分の生成はできたが、頭部と体の位置・縮尺が原画像から変わった。元絵を再現するレイヤー分解としては未達。
- 試作グループは非表示。初期プレビューは比較用原画像。実用的に分解できたことを示すPSDではない。
- 頭部／体のPNGでは透明画素のRGBにも背景色が残るが、それ自体は合成時には表示されない。

生成指示（3回）:
1. 原位置・原縮尺の全体キャンバスを維持し、髪・頭・顔・耳だけを残し、それ以外を透明化する。
2. 原位置・原縮尺を維持し、首から下の体・服・手・足だけを残し、それ以外を透明化する。
3. 人物を除去し、背後の暗いスタジオ背景を補完する。
いずれも1024×1536。1と2ではtransparent_background=trueを指定した。
実際の生成結果は位置・縮尺維持の指示を満たしていない。

ファイル:
- character_layers_trial_v2.psd: アプリで開ける検証用PSD
- assets/: 生成された3パーツ
- composite_v2.png: 初期表示（原画像）
- asset_report.json: 各PNGの寸法・モード・アルファ範囲
- exchange/: 実際の要求、結果、入力PNG、復帰用スナップショット
- Tests/SampleLayerTrial.dpr: 書出し・復帰・結果取込・PSD保存を実行した試験ランナー
