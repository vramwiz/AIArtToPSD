2026-10-01。目6種のユーザー採用を学習記録へ反映した後、依頼された眉の通常・喜怒哀楽・困る・左右非対称を作成した。内蔵image_genで1536×1024、2列×4段の両眉シートを1回生成。眉以外の透明化と前髪の遮蔽を確認し、アプリへ8種類を追加した。**ユーザーが「眉も問題なし」と確認し、8種類を成功例として採用済み。** [学習記録](learning_record.json)に成功条件・制約・成果物参照を保存した。

左右は画面基準。左右の眉を一組として生成・配置し、非対称形も顔全体の左右反転で作らなかった。細い灰褐色の眉線として残り、怒は眉頭を下げ、哀・困るは眉頭を上げる形になった。「喜」と「楽」、「哀」と「困る」の差は控えめ。画面左の眉は前髪に隠れる面積が大きく、左上げの変化は右上げより分かりにくい。眉単独では喜怒哀楽の表情を完成させるものではなく、採用済みの目・口と組み合わせて確認する。

## 生成・縮小・髪の遮蔽

生成指示全文は[prompt.json](prompt.json)。元の顔と、原画から抽出した眉の色・細さを参照。差分では両眉の全形を生成し、眉以外の肌・目・まつ毛・髪・影・光を禁止した。原画の前髪に隠れた部分を抽出したという意味ではなく、新しい表情として生成した形を合成時に遮蔽する。

各セルの540×160をアプリで108×32へ共通20%縮小。横方向のペア中心をx=504へ、行ごとに目視で決めた共通基準高さをy=145へ配置。行内の2種類は同じ高さの基準を用い、喜や非対称形の上下差を維持した。すべての可視範囲中心を揃えて感情による高さの変化を消す処理はしていない。

ベースに前髪が描かれているため、完全な眉をそのまま重ねると髪の上へ眉が出る。今回の原画に合わせ、キャンバス(450,129)～(558,161)の暖色の肌と青灰色の髪を区別する[brow_visibility_mask.png](brow_visibility_mask.png)を作り、髪に重なる眉画素を透明化した。処理は[prepare_layout.ps1](prepare_layout.ps1)。この狭い範囲でR>145、R−B>15、R−G>5を使用したもので、別の絵・髪色・肌色への汎用判定ではない。

元の生成シートは[brows_sheet.png](brows_sheet.png)として無変更で保存。アプリ入力は[brows_sheet_masked.png](brows_sheet_masked.png)。共通倍率20%に対応する5×5の元画素単位で遮蔽を適用し、残す画素のRGBは描き直さずアルファで除去した。アプリ縮小後の8枚でも、記録したマスクで除外した位置にはalpha>0の眉画素がないことを検証。肌側に残る線はチェッカーと顔合成で確認した。

この遮蔽は今回の固定配置用。眉の位置・倍率や髪型を変更したら、未加工シートからマスクを再計算する。既に切り落とした眉を移動しても、隠れていた部分は復元されない。微小な半透明画素によってPNG外枠が主要な線より大きくなる場合はある。

## アプリ・保存と検証

「眉差分8種（両眉・確認用）」を追加し、「03 怒」を表示。「眉（両眉・元画素）」は非表示で保持した。差分は一枚ずつ切り替えて確認する。目・口の表示は変更していない。アプリで顔全体として見るには、目グループのいずれか一つを表示する。

取込completed、revision 35→36、Undo可能。既存21画像のSHA-256、座標、階層、相対順序、不透明度等を照合し不変。既存属性の変更は原画眉の表示状態のみ。取込後のsnapshot.psdを別名保存した後、確認用exportをcancelした。最新ジョブの中止表示は取込の取消しではない。コード変更・既存PSD原本の上書きはない。
