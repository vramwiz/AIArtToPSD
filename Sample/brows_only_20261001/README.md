# 眉以外の透明化（2026-10-01）

目の髪除去をユーザーが成功と評価し、眉も同様に「眉以外を透明にする」追加ルールと、眉だけを編集画面へ送ることを指示。ルールをnote.mdへ記録した。その後、眉も成功とユーザーが確認。さらに口の周囲透明化を行い、[最終結果](../mouth_only_20261001/README.md)でベース・目・眉・口を採用した。

開いていたアプリPID33060は文書未読込だったため、目の修正済みスナップショットを復帰して作業。両眉の周囲の髪・肌を透明化し、replace_layerだけで反映。目・口・ベース・元画像は変更前後のPNGハッシュが一致し、全レイヤーの順序・名前・位置・表示・不透明度も一致した。

両眉は一枚、109×19、元キャンバス座標(449,134)～(558,153)。残した82画素は元画像RGBAと一致し、1,989画素は透明。前髪に隠れた眉は生成せず、元画像に見えている部分を残した。既存の眉輪郭マスクから周辺の影と髪の接点を除き、灰色の眉本体を色だけで誤削除しないよう確認した。この画像専用の指定であり、汎用的な自動分離器ではない。

最初の候補は眉本体の灰色画素まで削れたため、確認して目立つ途切れを修正した。draft-*はその中間結果。最終候補はbrows_only.png、アプリ文書のrevision=4。眉だけの置換でUndo可能。アプリコード変更、新規image_gen生成、拡縮、再描画は行っていない。

- brows_only.png：両眉一組、周囲透明。
- brows_review.png：上が元の矩形、下が眉だけの10倍表示。チェッカーは確認画像のみ。
- face_review.png／native_preview.png：実アプリの合成確認。
- brows_only_review.psd：実アプリが書き出した確認用PSD。既存PSD原本は変更なし。
- result.json／prepare_result.ps1：眉だけの置換と指示作成。
- prepare_brows.ps1／verify.ps1／verification.json：再現用処理と、元画素一致・他レイヤー不変・実アプリの出力一致の検証。
- export.json／import-response.json／snapshot-response.json：最終候補の交換記録。
