# 制作例とローカル素材

ここでは、成功条件や失敗理由を再利用するための `README.md`、`learning_record.json`、生成指示の `*prompt*.json`、最終検証の `verification.json` をGitで管理する。

PSD、PNG、入力画像、切り出した素材、交換ジョブ、パイプ応答、作業時点の文書JSON、一回限りの準備・検査スクリプトはローカル専用。これらは手元に保持し、GitHubへの同期から除外する。

各記録内の画像・PSD・中間データへの参照は、同じフォルダーにあるローカル資料を指す。cloneした環境で資料が必要な場合は、元の作業環境から必要な素材を相対配置を保ってコピーする。採用判断や再利用上の制約は、画像の有無から推測せず各記録を読む。

記録された過去のパイプ名、文書ID、ジョブID、レイヤーIDを再送しない。次の編集では、現在の接続先と文書から新しいexportを取得する。[全体の管理方針](../README.md)と[再開手順](../作業引継ぎ.md)を参照。
